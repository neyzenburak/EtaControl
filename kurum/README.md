# Kurum paketi

Yetkili kişiden alınan `EtaControl_KurumPaketi.zip` dosyasını bu klasöre kopyalayın; ZIP'i açmayın. Sonra proje kökündeki `KURULUM.ps1` dosyasını çalıştırın.

Paket yerel kurulumda otomatik doğrulanıp yüklenir. Kuruma özel bağlantı bilgileri, ekran tanımları ve eşlemeler bu pakette bulunur. Paket GitHub'dan indirilmez ve bu depoya eklenmez.

Gerçek işletme verilerini, Excel girdilerini, terminal kayıtlarını veya kişi listelerini bu klasöre koymayın. Bunlar uygulamanın yerel veri alanında yönetilir.
